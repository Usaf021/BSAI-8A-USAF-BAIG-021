# BSAI-8A-USAF-BAIG-021

This repository contains the assignments and visual analysis work completed for the Data Visualization course, covering both Week 1 and Week 2.

## Overview

The project includes:
- Week 1 notebooks and datasets focused on chart selection, data storytelling, and exploratory visualization.
- Week 2 notebooks and datasets focused on visual perception, Gestalt principles, cognitive load, and channel effectiveness.
- Plot exports and supporting files generated during the assignments.

## Repository structure

- `week 1/` — Week 1 assignments, notebooks, data, and plots
- `week2/` — Week 2 assignments, notebooks, data, and plots
- `README.md` — project summary and task overview

---

## Week 1 — Data visualization and chart choice

I completed the following assignments in Week 1:

1. Task 1 — Prove why we visualize using `datasaurus.csv`
   - Explored how datasets with nearly identical summary statistics can look completely different when visualized.
2. Task 2 — Trends and the spaghetti problem using `gapminder.csv`
   - Built and refined charts to show long-term trends while reducing visual clutter.
3. Task 3 — Distributions and relationships using `penguins.csv`
   - Investigated variable distributions, relationships, and a real Simpson’s paradox scenario.
4. Task 4 — Choose the right chart, five times using `mpg.csv`
   - Matched different chart types to different questions and justified each choice.
5. Task 5 — Time series analysis using `flights.csv`
   - Examined seasonal patterns and long-term movement in flight data.

### Week 1 outputs

- Notebook files: `week 1/task1.ipynb` to `week 1/task5.ipynb`
- Data files: `week 1/data/`
- Plots: `week 1/plots/`

## Week 2 — Visual perception and design effectiveness

I completed the following assignments in Week 2:

1. Task 1 — Preattentive attributes and visual search
   - Analyzed search speed and feature-based attention using generated stimuli.
2. Task 2 — Gestalt principles of grouping
   - Examined proximity, similarity, continuity, and other grouping effects.
3. Task 3 — Cognitive load and data-ink ratio
   - Evaluated clarity, redundancy, and chart efficiency using `car_crashes.csv` and `tips.csv`.
4. Task 4 — Channel effectiveness, measured
   - Compared visual channels using `channel_trials.csv` and `iris.csv` to assess perceptual decoding quality.
5. Task 5 — Capstone redesign of a chart for human visual system
   - Reworked a chart to improve readability and align with perception-based design principles.

### Week 2 outputs

- Notebook files: `week2/task1.ipynb` to `week2/task5.ipynb`
- Data files: `week2/data/`
- Generated stimuli and analysis CSVs: `week2/`
- Plot exports: `week2/plots/`
